# CommMonit 串口旁路监控

CommMonit 是一款 Windows Qt 桌面工具，用于在目标程序已经打开串口之后，附加到该进程并观察后续串口收发数据。

## 工作原理

Windows 串口由 `CreateFile` 以独占方式打开，第二个程序不能再直接打开同一端口。CommMonit 因此采用用户态进程附加方式，在目标进程内观察 `ReadFile`、`ReadFileEx` 和 `WriteFile` 调用：

- 不抢占、不关闭目标程序的串口；
- 支持在串口已经打开后再开始监控；
- 支持同时监控多个目标进程；
- 串口关闭后自动停止对应监控，其余串口继续运行；
- 同时展示十六进制和 ASCII；
- 支持暂停、方向筛选、文本筛选、复制与 CSV/JSON 导出；
- 支持快速切换工业风暗色/亮色主题并记住选择；
- 可通过“软件多开”按钮启动独立实例；
- 无需安装内核驱动。

## 使用

1. 以管理员身份运行 `CommMonit.exe`。
2. 在左侧“进程”页选择占用串口的目标进程。
3. 点击“监控所选进程”。
4. 目标进程下一次读写串口时，数据会出现在事件表中。

“串口设备”页仅用于查看系统识别到的 COM 设备。如果列表里没有目标程序或设备，请点击刷新。受保护进程、反作弊/安全软件保护的进程或高权限系统进程可能拒绝附加。

## 已知边界

- 这是用户态 API 观察方案，不是内核串口过滤驱动。
- 目标程序必须通过常规 Windows 文件 I/O API 访问串口。
- 目标程序退出、重启或主动阻止进程附加后，需要重新选择并附加。
- 已在附加前打开的串口可以捕获后续数据，但端口名可能显示为句柄；波特率和帧格式仍会显示。
- 32/64 位目标均由 Frida 后端处理，但受保护进程仍可能无法访问。

## 从源码运行

需要 Python 3.11+：

```powershell
python -m pip install -r requirements.txt
python main.py
```

演示界面：

```powershell
python main.py --demo
```

## 打包

```powershell
.\build.ps1
```

输出位于 `dist\CommMonit.exe`。
